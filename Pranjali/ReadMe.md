Milestone 1

## 📘 Overview
This milestone focuses on the **data collection and preprocessing** phase for integrating **medical imaging data (Brain MRI)** with **Electronic Health Records (EHR)**.  
The objective is to ensure both datasets are cleaned, standardized, and ready for further analysis and model development.

## 🧩 Files
- **milestone1.ipynb** → Jupyter Notebook containing the complete workflow for:
  - Loading and exploring Brain Tumor dataset
  - Loading and cleaning EHR dataset
  - Mapping and combining both datasets
  - Visualizing and validating merged results
- **README.md** → Summary of my milestone contribution.

## 📚 Datasets Used
As datasets are large, only references are provided below:
1. 🧠 **Brain Tumor MRI Dataset**  
   Source: [Kaggle - Brain Tumors Dataset by Mohammad Hossein](https://www.kaggle.com/datasets/mohammadhossein77/brain-tumors-dataset)  
   Description: MRI images categorized as glioma, meningioma, pituitary, and normal brain images.

2. 🏥 **EHR (Electronic Health Record) Dataset**  
   Source: [Kaggle - EHR Dataset by Gaurav Srivastav](https://www.kaggle.com/datasets/gauravsrivastav2507/ehr-dataset)  
   Description: Contains anonymized patient-level health data used for correlation with MRI image data.

## ⚙️ Workflow Summary
1. **Data Loading & Inspection**  
   - Loaded EHR and MRI dataset structure.  
   - Verified data consistency and inspected missing values.  

2. **Data Cleaning & Preprocessing**  
   - Removed duplicates and missing entries.  
   - Normalized categorical fields and standardized labels.  

3. **Dataset Integration**  
   - Mapped patient-level EHR data with MRI-level image metadata.  
   - Prepared combined dataset for next milestone (feature extraction & modeling).  

4. **Visualization & Validation**  
   - Visualized random MRI samples.  
   - Verified dataset distribution post-cleaning.
